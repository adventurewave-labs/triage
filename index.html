Three pillars, one system

The firm's formula is data + relationships + judgment. Triage makes each pillar a legible subsystem — and the chassis generalizes: swap "company" for "bond issuer" or "acquisition target" and nothing structural changes.

DATA

Signal layer

Live ClinicalTrials.gov and openFDA adapters produce signals with citable URLs. Per-type freshness windows; stale evidence is flagged, never silently used.

RELATIONSHIPS

Entity graph

Deterministic-first resolution with a human review queue — wrong merges poison scores silently, so they never auto-merge. Warm paths across the network in two taps.

JUDGMENT

Red-teamed rubric

A versioned rubric in git. Every score survives a hard citation gate (unresolvable claims don't ship) and an adversarial pass whose survivors become the bear case.

Proven, not asserted

Before v0.1.0 was cut, it was validated continuously in three environments — and every failure along the way was root-caused in the open.

The honesty contract

This project's core design decision is that trust compounds — so the system is honest about what it knows and what it doesn't.

  • The citation gate is hard. A scorecard whose claims don't resolve to stored evidence doesn't ship — enforced at the schema boundary, not by prompt exhortation.
  • The demo corpus is synthetic and watermarked. Every simulated entity carries a sim: prefix; the demo never passes synthetic data off as proprietary.
  • Calibration says where it's wrong. The golden set is real companies with real public outcomes; the report carries its own confounds and sample-size caveats.
  • Nothing silently dropped. Companies with insufficient evidence appear in the declined section with a machine-readable reason — the recall safety net.
  • Arguing with it is the feature. Overrides take ≤10 seconds, carry a reason code, and become eval cases. A first-pass product nobody disputes is dead.

Run it

Zero build, one store, five commands to the briefing.

# clean-room validated path (Node ≥ 20, pnpm 12)
pnpm install
pnpm seed          # watermarked synthetic corpus
pnpm brief         # ranked weekly briefing + declined section
pnpm web           # UI → http://127.0.0.1:8080 (overrides, calibration)
pnpm calibrate     # golden-set calibration report (honest notes included)

# the same intelligence as agent tools
pnpm mcp           # MCP server: 6 triage_* tools

# real, citable signals
pnpm ingest --live # ClinicalTrials.gov + openFDA adapters
